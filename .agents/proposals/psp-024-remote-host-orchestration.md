# PSP-024: Remote Host Orchestration

## Part 1: Concept & Proposal

### 1.1 Summary
Enables PodScript to deploy and manage containers on remote hosts using Podman's remote API and SSH.

### 1.2 Motivation
Users currently must install and run PodScript locally on the target host. Remote execution allows centralized orchestration and deployment to multiple nodes from a single local machine, greatly simplifying fleet management.

### 1.3 Goals & Non-Goals
* **Goals:**
  * Support the `CONTAINER_HOST` environment variable and `--remote` flag in Podman commands generated by PodScript.
  * Ensure configuration and recipes can be parsed locally while commands are executed remotely.
* **Non-Goals:**
  * Full cluster management or multi-node swarm orchestration (like Kubernetes or Docker Swarm).
